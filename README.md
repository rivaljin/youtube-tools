# 유튜브 콘티 도구

공개 도구 코드와 가상 기능 예시만 포함합니다. 실제 대본·콘티는 비공개 `rivaljin/nampy-assets/youtube/conti`에 보관합니다.

예정 주소(배포 확인 전): https://rivaljin.github.io/youtube-tools/cook-conti.html

[사용법·백업·이전·오프라인 안내](CONTI.md)

## Pages 설정 대기

현재 API 인증은 Pages 생성 권한이 없어 활성화하지 못했습니다. 저장소 Settings → Pages → Source: Deploy from a branch → main → /(root) → Save를 선택하세요. 실제 배포 확인 전까지 기존 https://rivaljin.github.io/blog-tools/cook-conti.html 을 사용합니다.
