## 배포 확인

GitHub Pages는 main / (root)에서 배포합니다. 실제 HTTPS에서 도구의 HTML·JS·CSS와
서비스 워커가 로컬 테스트 소스와 일치함을 확인했습니다. 기존 주소에는 백업용 도구를
유지합니다. 촬영/복원/새 경로 오프라인 테스트는 로컬 Chromium에서 통과했습니다.
iOS 실기기에서는 온라인으로 한 번 열고 오프라인 준비 완료 후 비행기 모드로 확인하세요.
